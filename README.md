# Password Generator - by Wade

A simple Python tool that generates strong passwords.

## How it works
- Ask your name with `input()`
- Generate random number with `randint(100, 999)`
- Pick random letter with `choice()`
- Create 5 strong passwords with a `for loop`

## Example
Input: wade
Output: wade389C!, wade830B!, wade716A!, wade666E!, wade528D!

Built with Python and the random module.
